# HD2 双护甲被动

本模组通过 Bingus Shared Loader, 在当前身甲自带被动之外, 为人物添加一套可选的护甲被动. 它修改头盔的被动数据, 不改变身甲、头盔或披风外观. 本质是双甲 bug 的延伸, 但涉及内存读写, 请酌情使用. 完全 vibe 产物, 0 % 人类含量.

## 安装与更新

1. 在 HD2 Arsenal 中启用 [Bingus Shared Loader](https://github.com/CowboyBingus/BingusSharedLoader/releases) v15 或更新版本. 本次已使用 v19 实测.
2. 下载 v1.1.0 的 [HD2-Dual-Armor-Passive.zip](https://github.com/MisakaTukasa/HD2-Dual-Armor-Passive/releases/download/v1.1.0/HD2-Dual-Armor-Passive.zip). 如果安装过旧版本包, 先在 HD2 Arsenal 中移除旧条目, 再导入新 ZIP, 启用模组并重新部署.
3. 启动游戏, 在舰船按默认 F9 检查菜单是否打开; 修改过快捷键时, 使用你保存的键位.

更新会保留原被动选择和已保存的快捷键.

## 选择额外被动

- 在舰船或出击准备界面按菜单快捷键打开菜单; 默认 F9, 任务中不能打开.
- 用鼠标点击列表项, 或用方向键选择和翻页. 点击“确认”或按 Enter 应用.
- 再按菜单快捷键、Esc 或点击“关闭”退出菜单. 菜单打开时, 鼠标点击不会穿透到原生界面; 关闭后原生点击恢复.
- 选择“无额外被动”并确认即可关闭额外被动. 当前身甲原有被动继续由游戏处理.
- 选择会保存, 下次启动自动恢复. 使用游戏原生军械库更换身甲或头盔后, 已选额外被动也会继续应用.

菜单提供 31 种护甲被动, 包括*尚未拥有的护甲*对应的被动. 游戏语言设为简体中文时, 菜单显示游戏中的简中名称; 其他语言暂显示英文.

身甲与额外槽选择同一种被动时, 重复效果由游戏原有规则处理. 已实测重复“急救包”仍为 6 支针, 不会叠加到 8 支; 其他被动的重复效果尚未逐一验证.

## 修改菜单快捷键

默认 F9, 只支持 F1-F12 单键.

1. 打开菜单, 点击“修改快捷键”.
2. 先松开所有 F 键, 再按一个 F1-F12 键保存.
3. 松开后即可使用新键位. Esc 取消录入, “恢复 F9”恢复默认设置. 保存失败时保留原键位.

如果快捷键冲突导致菜单不便打开, 可以退出游戏后修改以下文件:

`%LOCALAPPDATA%\CowboyBingus\Helldivers2\HD2DualArmorPassive.ini`

例如改为 F10:

```ini
settings_version=1
menu_hotkey=f10
```

重新启动游戏后生效. 配置缺失或格式无效时使用 F9.

## 游戏更新与兼容性

v1.1.0 不以 Steam 游戏版本号作为启动限制. 游戏小更新后, 仍符合支持条件时可以继续使用; 检查失败会拒绝相关操作并记录原因. 不保证兼容性和及时更新, 但会尽量做.

目前只对部分代表效果做过实机验证, 其余被动尚未逐一验证. 新版与其他 mod 共载暂未实测; 修改菜单键位可以避开快捷键冲突, 但不能保证所有 mod 之间兼容.

## 排查问题

- 菜单打不开时, 确认 Bingus Shared Loader 和本模组都已启用并部署, 在舰船或出击准备界面使用当前保存的菜单键位.
- 快捷键与其他 mod 冲突时, 按上面的配置文件方法修改键位, 然后重启游戏.
- 确认时显示“应用失败”表示本次选择未完成. 请查看日志中的失败原因后重试; 游戏更新后出现异常时也可查看日志.

日志位置:

`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\HD2DualArmorPassive.log`

保存的被动选择位于 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\HD2DualArmorPassive.cfg`.
